# Pipeline: $ARGUMENTS

Read `career/applications.md`, `career/referrals.md`, `career/interview-log.md`, `progress/profile.md` (tiers,
notice period, resign-by), `career/company-notes/*.md` (observed time-to-offer), `date +%F`.

- **update** (weekly, ≤ 15 min): ask what changed (new applications, OA invites, screens, loops, results);
  update rows (stage + dates + next action with a date); list overdue next actions and referral follow-ups
  (5–7 days); refresh the funnel summary and `progress/metrics.md` (applications, interviews).
- **plan** (CO.3.3 and whenever timing shifts): work backwards from the target offer window (≈ late May–mid
  June 2027; adjusted to the resign-by date): per company, typical time-to-offer (observed > recruiter-stated >
  reported, mark verify) → latest apply date. Order: practice tier first, dream tier when sharpest but early
  enough to land with the others. Cap live loops at ~3 per week; plan leave at work; note re-apply cooldowns
  before applying to dream companies too early.
- **Diagnose** conversion honestly: low applied→screen (resume/targeting/referrals), low screen→loop
  (recruiter screen/OA speed → DSA repo), low loop→offer (weakest round type → that repo).
- **Batching tactics**: ask recruiters for timelines; if one company is fast, it's acceptable to tell others
  truthfully "I'm in final rounds elsewhere; can we speed up?"; ask for a deadline extension when an early
  offer lands.

Finish: wrap-up protocol (README funnel table, STATUS log line, hours).
