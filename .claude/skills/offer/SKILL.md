# Offer: $ARGUMENTS

Read `career/negotiation.md`, `career/offers.md`, `progress/profile.md` (target definition, notice period,
current CTC), `career/applications.md` (other live processes).

**Rules:** numbers only from the learner's offer letters/recruiter emails; anything else (bands, vesting
norms) labelled **verify** with where to check; tax → "confirm with a CA"; never advise misrepresenting CTC,
offers or notice period.

1. **Decompose** each offer into the `offers.md` comparison table (ask for missing items: clawbacks, RSU
   schedule/cliff, variable payout history, joining date, buyout reimbursement).
2. **Compute** year-1 cash, year-1 total, 4-year average, approximate in-hand; show the arithmetic.
3. **Compare** against the target definition and each other, including level, team, growth, WLB, location.
4. **Plan the ask**: levers (level → joining bonus → RSUs → base → buyout/start date), the anchor, the
   walk-away number, which competing facts to use, the deadline strategy. Script it (§6) in the learner's voice.
5. **practice**: role-play the recruiter (big-tech band-bound; Indian startup with ESOPs; low-ball; exploding
   deadline). Stay in character until "Out of character"; then debrief phrasing and missed levers.
6. **Accept/exit**: after a signed letter, walk the Exit checklist (notice, early release, buyout, counter-offer
   stance, resignation email, handover, documents, PF).

Finish: `offers.md` updated (comparison + negotiation log + decision), wrap-up protocol.
