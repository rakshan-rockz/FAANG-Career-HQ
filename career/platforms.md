# Platforms & Channels (CO.2.2)

**Always truthful** on every platform: current CTC, notice period, titles and dates are cross-checked by
BGV and recruiters.

| Platform | Use it for | Setup checklist | Status | Notes |
|---|---|---|---|---|
| **LinkedIn** | Recruiter inbound, referrals, job alerts | Profile (linkedin.md), open-to-work (recruiters only), alerts for ranked companies | ⬜ | |
| **Naukri** | Indian recruiters & consultancies (high volume) | Profile 100%, resume v2, notice period field accurate, update weekly (recency ranking) | ⬜ | Expect spam; filter by company |
| **Instahyre** | Curated product-company matches | Profile, salary expectations, "actively looking" toggle when ready | ⬜ | |
| **Cutshort** | Startups / mid-size product cos | Profile, skills | ⬜ | |
| **Wellfound** (AngelList) | Startups, some with ESOPs | Profile, role preferences | ⬜ | Evaluate ESOP value skeptically |
| **Company career pages** | Direct applications (Amazon.jobs, Google Careers, Microsoft Careers, Meta Careers, Atlassian, Uber, Flipkart, PhonePe, Razorpay, Swiggy, Zomato, Walmart Global Tech, Adobe, Salesforce, Oracle, Intuit) | Account + alerts per tier-1/2 company; note job IDs | ⬜ | Referrals usually need the job ID |
| **Recruiters / consultancies** | Warm intros for some companies | Keep a list; never pay a fee; never let them apply without your OK (duplicate applications hurt) | ⬜ | |
| **Hackathons / hiring challenges** | Some companies hire via coding contests | Optional | ⬜ | |
